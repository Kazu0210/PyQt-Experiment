# PyQt Experiment

A lightweight experiment exploring the capabilities of PyQt6, focusing on window transparency, frameless UI, and aesthetic visual effects.

## Features
- **Fullscreen Mode**: Launches in a borderless fullscreen state.
- **Translucent Background**: Implements semi-transparent window backgrounds.
- **Neon Aesthetics**: Features a bright neon blue border for a modern, glowing look.
- **Frameless Design**: Utilizes `FramelessWindowHint` to remove OS window decorations.

## Requirements
- Python 3.10+
- PyQt6

## Installation
Install the required dependencies using pip:
```bash
pip install PyQt6
```

## Usage
Run the application directly from the terminal:
```bash
python main.py
```

## Project Goals
This project serves as a sandbox for testing UI/UX elements in PyQt6, specifically how to handle OS-level window flags and custom stylesheets for visual effects.
